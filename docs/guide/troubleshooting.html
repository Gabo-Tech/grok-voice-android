Troubleshooting

When a step stops.

The APK will not install

  • The phone must be arm64-v8a and Android 8 (API 26) or newer. A 32-bit device is refused because the native code is arm64 only.
  • Allow installs from the app that opened the file. That switch is per app, under Install unknown apps.
  • adb install -r fails with a signature mismatch when an older copy was signed by a different key. The release certificate SHA-256 is fd400ffe61c9b18654bc40f567275e5a6e13bab8d311355f389f6e46458aafe9. A locally built APK that you did not sign with that keystore will not replace the GitHub release.
  • Check the file size. The 0.1.65 asset is 58,162,590 bytes. A short download is not a complete APK.

Setup does not finish

  • Finish later does not discard the step. Open Settings, then Voice and AI, and continue the same path.
  • The on-device and 1min.ai paths need the English pack: 250,807,309 plus 144,811,360 plus 65,051,089 bytes. Use Wi-Fi. If a file fails its checksum, download that piece again from Voice and AI. Nothing new downloads until you tap Download.
  • A key that is too short was not copied whole. xAI keys usually start with xai-. OpenAI keys usually start with sk-. The 1min.ai key is under Settings, then API, at app.1min.ai.
  • A refused xAI key: create a new one and check that the account can spend. A refused OpenAI key: check billing on the platform. A refused 1min.ai key: copy it again and check credits.
  • If the network fails on a cloud path, try again, or put On this phone next in Voice and AI. Mixed mode uses the phone first and the saved cloud key only if the phone cannot answer.
  • A gated Phonon 40m model stays refused without a Hugging Face token, and without the license accepted on the model page. English Phonon 31m does not need that token. Valencian has no Phonon model and no Piper voice, so it stays on the Android voice. Portuguese has no Piper voice.

Talk is quiet or talks to itself

  • Allow the microphone. On this phone, say hello after the pack is ready. A cloud path needs a network.
  • Use headphones if the speaker feeds the microphone. Echo guard is on unless you turn it off in Debug.
  • Listen shows a notification while the microphone stays open. Stop on that notification ends it. Android may ask for unrestricted battery use. Without that, some phones kill the microphone later.
  • A force-stop stays off until you open the app and turn Listen on again. After a reboot, open the app once before background listening can use the microphone.
  • Settings shows background-listening status. A watchdog restarts the microphone if it stalls while Listen is on.
  • “Which model am I using?” calls get_settings. That tool never returns keys. For On device and 1min.ai, speech to text and the voice stay on the phone even when the reply is written elsewhere.

Money, colors, and deletes

  • “No rate is saved” means refresh rates, or set a manual rate in Settings. The app does not invent a rate and does not assume one-to-one.
  • Logging never creates an account or a card. If two names are close, Talk asks. Create one only by asking to add it.
  • A card payment is not a second expense. Charging a card raises what it owes and counts as an expense. Paying more than it owes is allowed and leaves a credit.
  • Cancelling a reminder, alarm, or countdown, deleting a person, and deleting a finance row, a budget, or a budget line ask for a yes first. The first call does not remove them. Filling a month runs only when you ask to set up or fill the budget.
  • A chart color is saved on the item. “Reset every chart color” asks, then clears saved colors only after yes. It does not delete the holdings.

Messages and calls

  • Message reading stays off until you turn it on under Settings, Phone access. Notification access is a system setting.
  • A reply is read back and sent only after a clear yes, and only when that app exposes a reply action. Otherwise a draft opens and you tap Send.
  • Opening the dialer does not place the call. place_call says the number and dials after yes. Answer, decline, and hang up happen only when you say so.
