Setup

Pick one path. The others can wait.

A new install opens a tour: Language, Choose, Guide, Try it. Finish later leaves the tour and keeps what is already on the phone. Settings, then Voice and AI, opens the same path again. An install that already finished setup is not sent through the tour.

The screen language is English, Spanish, German, Portuguese, or Valencian. The first offline voice stays English until you add another pack. The tour does not ask for a Hugging Face token.

On this phone

No key. Moonshine hears you, a local model thinks, and Phonon or Piper speaks. This is utterance mode: the phone waits until you pause, then answers. It is not the full-duplex barge-in of a cloud voice.

The first download is three files, 460,669,758 bytes in total:

PieceBytes
Moonshine Base English, int8250,807,309
SmolLM2 135M Instruct Q8_0144,811,360
Phonon 31m English65,051,089

Wi-Fi is the better way to fetch it. The screen shows the size and the progress. Piper English is 67,097,098 bytes and is the other on-device voice, not part of that first three-file pack. The phone recommends a stronger GGUF when memory and storage fit. Minimum RAM in the picker starts at 2 GB for SmolLM2 and LFM2.5, and is 8 GB for Qwen3.5 4B and Gemma 4 E2B.

Try it: play the voice, allow the microphone, then open Talk and say hello. A reply means this path works with no network, once the pack is on the phone.

If the download fails, retry from the same step. If the model cannot load, Voice and AI can pick a smaller pack, or you can add a cloud key as the next voice.

xAI

Hearing, thinking, and the voice run in the cloud.

  1. Open the xAI console and create an API key. Copy the whole key. It usually starts with xai-.
  2. xAI bills that key. This app does not charge you. Settings can warn you after a number of minutes.
  3. Paste the key, then save it. It stays in the vault on this phone.
  4. Allow the microphone, then open Talk and say hello. A spoken reply means the key works.

If the key is refused, create a new one and check that the xAI account can spend. If the network fails, try again, or add On this phone as the next voice. A key that is too short needs the whole value from the console.

OpenAI

Hearing, thinking, and the voice run in the cloud.

  1. Open the OpenAI platform and create a secret key. Copy the whole key. It usually starts with sk-.
  2. OpenAI bills that key. Realtime voice is their audio API. This app does not add a fee. Settings can warn you after a number of minutes.
  3. Paste the key, then save it. It stays in the vault on this phone.
  4. Allow the microphone, then open Talk and say hello. A spoken reply means the key works.

If the key is refused, create a new one and check billing on the OpenAI platform. If the network fails, try again, or add On this phone as the next voice.

1min.ai

A 1min.ai key writes the reply. Hearing and the voice stay on this phone, so this path still downloads the offline pack.

  1. Sign in at app.1min.ai, open Settings, then API, and copy the key.
  2. 1min.ai spends credits on your account for the reply. Hearing and the voice do not use those credits. This app does not add a fee.
  3. Paste the key, then save it. It stays in the vault on this phone.
  4. Download the English hearing and voice packs. Then open Talk and say hello. You are heard on this phone, and 1min.ai writes the reply.

If the key is refused, copy it again and check that the account has credits. If the reply never starts, download Moonshine and the voice pack, then try Talk again.

Phone, then a cloud key

This phone answers first. A saved cloud key is used only if the phone cannot. Download the offline pack, then save one cloud key: xAI, OpenAI, or 1min.ai. The order in Voice and AI is the fallback order. Downloaded, key set, and offline-ready show at the top of that screen.

Try it the same way: allow the microphone and say hello in Talk. If the phone pack is missing, Talk moves to the saved cloud key.

After the tour

Settings, then Voice and AI, is the one screen for hearing, the model, the voice, and the order Talk tries. Spanish and German speech packs, Piper, the Android voice, and Phonon models that need a token are added there. A Hugging Face token is stored in the same vault and is sent only for a gated download. English Phonon 31m does not use it.

You can replay the tour from Voice and AI, or from Debug, then Replay setup tour.
