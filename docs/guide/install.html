Install

Sideload the APK.

The current release is an arm64 package for Android 8 and newer. It is not a Play Store upload.

GrokVoice-0.1.64.apk

58,146,206 bytes. sha256 932f66af1bb2f6e4784d8e5e665a716b5a96a8392ea03e221cb3b467cf94a2c0. versionName 0.1.64. versionCode 1064. ABI arm64-v8a. minSdk 26.

On the phone

  1. Download GrokVoice-0.1.64.apk from the link above, or from the latest release when that asset is this file.
  2. Open the file. If Android blocks it, allow installs from this source for the browser or the files app. The wording is “Install unknown apps” on Android 8 and newer.
  3. Confirm the install. An update over an older Grok Voice uses the same sideload certificate, so Android replaces the existing app and keeps its data.

A 32-bit phone cannot install this APK. The native libraries are arm64-v8a only.

From a computer

With the phone in developer mode and USB debugging on:

adb install -r GrokVoice-0.1.64.apk

-r replaces an existing install signed with the same certificate. A different signature is refused. Uninstalling first deletes the on-phone data.

What the signature is

GitHub Actions signs the release with the repository sideload key and checks certificate SHA-256 fd400ffe61c9b18654bc40f567275e5a6e13bab8d311355f389f6e46458aafe9. The project describes that key as the debug certificate used for hand installs. It is not Play App Signing. Details are in the developer notes.
