Android · on the phone by default

A voice assistant on your phone.

Say “Hey Grok” with the screen off. A new install answers on the phone, with no cloud key. Notes, calendar, reminders, and money stay on the phone. xAI and OpenAI are optional.

Download Grok Voice 0.1.57 Source

Arm64 APK · Android 8 and newer · signed in GitHub Actions

Talk, or type

Wake word

Listen stays on after you leave. A watchdog restarts it if the microphone stalls, and Settings shows that status. Nothing starts until you say “Hey Grok.”

Quiet gap

After a pause you choose, from 5 to 120 seconds, the conversation ends and only the wake word remains.

A page for notes

Titles, search, and Markdown. Preview headings, lists, and links before you save.

On the phone

  • NotesSave, retitle, and search what you asked Grok to remember.
  • RemindersTalk saves reminders, alarms, and countdowns on Time. They fire through this app’s notifications. An alarm can use the phone sound, an audio file you pick, or a YouTube video. “In 5 minutes” is an in-app reminder.
  • CalendarTalk saves new events on the app calendar. Reading the phone calendar is unchanged. An event added on the Calendar screen, while access is granted, still goes to the phone calendar.
  • FinanceAccounts, spending, cards, crypto, and custom assets stay on this phone. Talk can log money and read what is saved. There is no bank login. Voice commands: English, Español, Deutsch, Português, Valencià.
  • MusicTalk plays with the default player in Settings. Files on this phone are the default. Musify, when installed, can be chosen and searched by voice. If it cannot play, YouTube opens, then the YouTube site in the browser. Saying “on YouTube” still waits for a yes. A search does not start playing by itself, and nothing is downloaded.
  • SearchNews, weather, and what is on in town, spoken and written, with sources.

Voice and AI

Settings has one Voice and AI screen. From there you pick who hears you, which model thinks, which voice speaks, and the order Talk tries if the first one fails. On this phone can sit next to xAI and OpenAI. A key is typed on the provider it belongs to. Downloaded, key set, and offline-ready show at the top.

The first launch downloads one English pack: Moonshine, SmolLM2, and Phonon 31m. It shows the size and the progress, and it asks for Wi-Fi. There is no Hugging Face token and no other-language pack in that tour. The screen language can still be Spanish, German, Portuguese, or Valencian. Those voices, Piper, and the gated Phonon models can be added later in Voice and AI. The tour can be paused and finished later from that screen. An install that already finished setup is not sent through it again.

The on-device engine is Phonon, Piper, or the Android voice, or Auto. Auto uses Phonon when that language already has a model, otherwise Piper, then the Android voice. If Phonon fails, Piper speaks, and the Android voice is next.

Phonon is Gradium’s on-device speech engine. It builds on Pocket TTS and the Mimi codec from Kyutai. The runtime is xn-ptts, MIT or Apache 2.0, and it runs on the phone with no PyTorch. English Phonon 31m is Apache 2.0 and needs no account. The 40m models are CC BY-NC 4.0 and gated on Hugging Face. This app is non-commercial, so those terms allow them. Accept the license on the model page, then save a Hugging Face token in Voice and AI. The token stays in the on-device vault and is sent only for that gated download. English 31m works with no token. Valencian has no Phonon model, so it keeps Piper when a voice is installed and otherwise the Android voice. Portuguese has no Piper voice; Phonon speaks it after the model is downloaded.

Moonshine speech-to-text, SmolLM2, and the Piper packs are still there, under the same screen. Nothing new downloads until you tap Download. After that, the voice is offline.

Privacy

This app has no server of its own and does not collect analytics. The key is stored encrypted on the phone. Wake-word audio is checked on the device and is not uploaded. Notes, reminders, and in-app events stay in a local file.

The default conversation stays on the phone. If you add a cloud provider, that part of the talk is not private from them. An xAI key is sent to api.x.ai to mint a short-lived voice token, and speech goes to xAI only while xAI is the provider in use. OpenAI works the same way with its own key. A typed question that uses a cloud model is sent there too.

Questions

What is Grok Voice?
A voice assistant for Android. A new install talks on the phone in English, with Moonshine, SmolLM2, and Phonon 31m. No account and no token. The screen can use another language. Other voice packs are optional in Settings. An xAI or OpenAI key is optional. The wake word stays on the device. The app is free and open source under the MIT license.
How do I install it?
Download the arm64 APK for Android 8 and newer from the GitHub releases, then open it on the phone or install it from a computer with adb. The release APK is signed in GitHub Actions, so it installs over an existing install. It is not a Play Store upload.
Where does my API key go?
A cloud key is optional. If you add an xAI or OpenAI key in Voice and AI, it is stored encrypted on the phone. An xAI key is sent to api.x.ai only to mint a short-lived voice token, and only while that provider is in use. The default voice does not need a key. A Hugging Face token, if you add one, is used only to download a gated Phonon model.
Can the phone speak without a cloud key?
Yes. That is the default, in English: Moonshine, SmolLM2, and Phonon 31m, with no token. Voice and AI is one screen for hearing, the model, the voice, and the fallback order. The first launch downloads only that English pack and can be finished later from Settings. Spanish, German, Piper, and gated Phonon models are optional there. Phonon is Gradium’s on-device engine, built on Kyutai’s Pocket TTS and Mimi codec. Once a model is downloaded, that voice works offline.
Are wake-word recordings uploaded?
No. Wake-word audio is checked on the device and is not uploaded. “Hey Grok” is trained on the phone from three recordings you make, and those samples are not uploaded.
