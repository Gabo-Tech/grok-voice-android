The key stays here

You paste a key during setup. The app checks it, then locks it in on-device storage. Voice uses a short-lived token minted on the phone. Wake-word recordings are not uploaded.

You can keep more than one key, in the order you prefer. If the first connection fails, the next is tried. Spoken replies use xAI realtime voice today.

Questions

What is Grok Voice?
A bring-your-own-key voice assistant for Android. The phone talks to the xAI Realtime API directly. Audio, the wake word, and your API key stay on the device. The app is free and open source under the MIT license.
How do I install it?
Download the arm64 APK for Android 8 and newer from the GitHub releases, then open it on the phone or install it from a computer with adb. The package is signed for sideloading. It is not a Play Store upload.
Where does my API key go?
You paste an xAI API key during setup. The app checks it, then stores it in an on-device vault. Each voice session uses a short-lived client secret minted on the phone. The long-lived key is not sent on the WebSocket.
Are wake-word recordings uploaded?
No. “Hey Grok” is trained on the phone from three recordings you make. Those samples are not uploaded. Hands-free listening can stay on after you leave, including with the screen off.
What can I ask?
Notes, timers, alarms, reminders, and calendar events. The assistant acts on the phone, then tells you what happened.
