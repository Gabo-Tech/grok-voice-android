Say Hey Grok. The phone answers.

A voice assistant that stays on the device. Listen for the wake word with the screen off, type when you can’t talk, and keep notes, calendar, and reminders on the phone.

Talk, or type

Wake word

Turn Listen on and the phone keeps waiting for “Hey Grok”, including after you leave the app. No wake word, no session.

Quiet gap

When the conversation goes quiet, it hangs up and listens only for the wake word again. You set the pause, from 5 to 120 seconds.

Text

Type on the Talk screen when it’s loud or you can’t speak. The answer lands in the same thread, and links open in the browser.

It can use the phone

  • Notes Save, edit, and delete notes on the device.
  • Reminders One-off alerts, alarms, and timers.
  • Calendar Today’s list, plus a month you can move through. If the phone calendar is unavailable, events stay in the app.
  • Search Ask for today’s news, weather, or what’s on in town. The answer is spoken and written, with sources.

The key stays here

You paste an API key during setup. The app checks it, then locks it in on-device storage. Voice uses a short-lived token minted on the phone. The long-lived key is not sent on the voice connection. The wake-word recordings never leave the device.

You can save more than one key and put them in order. If the first connection fails, the next one is tried. Spoken replies run on xAI’s realtime voice. Other saved keys wait until that provider’s voice connection is ready.

Install

Download the latest release, then install it on the phone.

adb install -r GrokVoice-0.1.7.apk
